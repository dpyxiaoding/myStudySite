# 编程智能体对读

把同一道题放到三个编程智能体里对照着读：**Claude Code**、**codex**（Rust）、**deepseek-harness**（TypeScript）。部分篇目还把我自己的项目 agent-platform 作为第四列一起比较。

## 这个系列在做什么

单家盘点回答「它有什么」，横向对读回答「同一道题，三家各给了什么答案，哪几处它们互相矛盾」。后者才产出可用的判断：三家撞出同一个答案的可以当定论，三家分歧的说明这里没有标准解，要自己判断。

每一篇的骨架固定：

1. 这件事在解决什么：把问题拆到「不读代码也能看懂为什么难」
2. 三家是谁，证据到什么档次：先声明哪几格是猜的
3. 若干个维度，按流水线顺序排，每个维度给三家各一段，末尾一句判断：同构还是分岔
4. 分岔汇总表
5. 对自己的项目意味着什么：同构可当定论 / 没有的要不要补 / 三家分歧要自己判
6. 证据档次与明确没核到的部分
7. 落点索引
