# codex 功能介绍

codex 是 OpenAI 的编程智能体：读代码、改文件、跑命令，接上外部工具干活。本组按[智能体功能简介](/agents/overview)的清单，一项一项介绍它是怎么做的。

## 基本情况

| 项目 | 情况 |
| --- | --- |
| 出品 | OpenAI |
| 源码 | 全部公开，Apache-2.0 许可证。核心是 Rust 写的 `codex-rs` 工作区 |
| 使用形态 | 终端命令行、IDE 插件、ChatGPT 桌面应用里的 Codex、云端任务 |
| 本组核对的版本 | 发布版 rust-v0.162.1（2026-10-09）；源码读的是 2026-10-11 的 main 分支，提交 `8c0f701`；文档读取于 2026-10-11 |

## 本组的依据

- **源码**：行为、数值、数据结构都以源码为准，文中写出文件路径（相对 `codex-rs/`）。数值取自源码常量和内置的模型清单 `models-manager/models.json`，没有实际运行验证。
- **官方文档**（learn.chatgpt.com/docs，原来的 developers.openai.com/codex 已迁到这里）：命令、配置项以文档为准。文档和源码对不上时，以源码为准并注明。

源码里有不少功能放在开关后面，标着「开发中、默认关闭」。各篇只把默认打开的行为当作 codex 的做法，开关后面的单独注明。
