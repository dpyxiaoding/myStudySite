# Claude Code 功能介绍

Claude Code 是 Anthropic 的编程智能体：读代码、改文件、跑命令，接上外部工具干活。本组按[智能体功能简介](/agents/overview)的清单，一项一项介绍它是怎么做的。

## 基本情况

| 项目 | 情况 |
| --- | --- |
| 出品 | Anthropic |
| 源码 | 引擎不公开。Agent SDK 的 Python 版源码公开（MIT 许可证，使用受 Anthropic 商业条款约束），但它只是调用 Claude Code 的一层封装，能看到接口和数据格式，看不到引擎内部逻辑 |
| 使用形态 | 终端命令行、VS Code 和 JetBrains 插件、桌面应用、网页版（云端会话）；也能用 Agent SDK 嵌进自己的程序 |
| 本组核对的版本 | 2.1.296（2026-10-09 发布），文档读取于 2026-10-11 |

## 本组的依据

引擎闭源，所以本组的内容来自四类公开资料：

- **官方文档**（code.claude.com/docs）：行为、配置项和取值以它为准。
- **Agent SDK 源码**：数据结构和字段名以它为准。
- **Anthropic 工程博客**：设计理由以它为准。
- **更新日志**：用来确认某个行为从哪个版本开始，以及修过哪些问题。

2026-03 流出的源码不采用。文档没写的地方，各篇会直接写「文档没写」，不做推测。
