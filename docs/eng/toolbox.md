## 它不只是这个终端

上一版整篇默认「Claude Code＝你面前这个终端」，这是最大的一处漏。同一个账号、同一套配置，有十个入口。这一节没有一行带记号——这个项目一个都没用到，但它们决定的是「离开这台机器之后还能不能继续」。

### 你自己坐在前面的

- **终端 CLI** — 你现在用的这个。功能最全，其余形态基本是它的投影
- **Claude Code on the web** — 会话跑在 Anthropic 托管的云端环境里，本机可以关掉。*「先起一个跑着，回头再看」这类活它才是对的形态*
- **桌面 App** — macOS / Windows，Linux 是 beta，另有 WSL 版。多个会话并排看；`/desktop` 把当前终端会话交接过去
- **手机 App** — `/mobile` 出二维码。单独装没用，要配下面这条
- **Remote Control** — *把本机这个会话接到手机或另一台机器上继续*。`PushNotification` 的手机推送、`SendUserFile` 把文件发到你设备上，都要它连着才成立

### 嵌在别的工具里

- **VS Code · JetBrains** — 官方扩展与插件，`/ide` 管连接状态。diff 在 IDE 里看，选中的代码自动进上下文
- **Chrome** — 驱动你本机的 Chrome：点击、填表、截图、读 console
- **CLI computer use** — 比 Chrome 更远一步——让它操作你的电脑本身，不限于浏览器
- **Slack（Claude Tag）** — `/install-slack-app`。在频道里 @ 它，它在你的仓库上干活并把结果回到线程里

### 没有人坐在前面的

- **GitHub Actions** — `/install-github-app` 一条命令装好 App、workflow 和 secret。PR 里 @claude 触发。GitHub Enterprise Server 单独有一页
- **GitLab CI/CD** — 同一件事的 GitLab 版；交互模式里还能直接看 MR 的评审状态
- **`claude -p` 无头模式** — 脚本里跑，输出可选 JSON / stream-JSON。`--bare` 跳过全部自动发现，专为「每台机器结果一致」
- **Agent SDK** — *整个 SDK 面上一版一个字没提*。TypeScript 与 Python，把这套 agent loop 当库用：自定义工具、权限回调、hooks、子智能体、结构化输出、会话持久化、成本追踪。**你在做的正是同一类东西**
- **Routines** — claude.ai 上的云端定时 agent（`/schedule` 背后就是它），跑在云里不占本机
- **deep links** — 一条链接直接拉起一个带好上下文的会话，适合写进文档或 issue 模板

## 键盘与输入

上一节只列了六个键，官方交互模式那页有整整三张表。下面是其中你按下去会有明显收益的部分，按原文核过。*这一节的收益不在「知道有这个键」，在于其中几条能把一次 `/clear` 变成一次按键。*

### 干活时随手按的

- **Ctrl+O** — 开关转录视图：展开每次工具调用的细节、每条回复的时间戳与实际用的模型。默认折成一行的 MCP 调用也在这里展开
- **Ctrl+B** — 把正在跑的 bash 命令或子智能体挂到后台（tmux 里按两下）。*不用一开始就决定挂不挂后台，跑起来再改主意*
- **Ctrl+T** — 显示 / 隐藏它的任务清单。看后台跑着什么用 `/tasks`，不是这个
- **Ctrl+X Ctrl+K** — 停掉本会话所有后台子智能体（3 秒内按两次确认），顺带关掉 artifact 自动回评论
- **Alt+T · Alt+O · Alt+P** — 依次是：开关 extended thinking、开关快速档、换模型（都不清空输入框）
- **Ctrl+L** — 重绘屏幕。花屏或半空白时先按这个，别急着重启
- **Ctrl+Z** — 挂起进程回到 shell，`fg` 回来。仅 Unix

### 输入框里的

- **打字不用等** — *它干活的时候直接打，回车排进队列*，它做完自动接上；`Up` 可以把排队的收回来改
- **Ctrl+G · Ctrl+X Ctrl+E** — 用你的默认编辑器写这条 prompt。*长指令在 vim 里写完再回来，比在单行框里搏斗省事*
- **Ctrl+S** — 把当前输入暂存起来清空；再按一次连光标位置和粘贴内容一起取回
- **Ctrl+R** — 反向搜历史命令，交互式
- **Ctrl+V · Alt+V** — 粘贴剪贴板里的图，插入 `[Image #N]` 占位符。*Windows 和 WSL 上用 Alt+V*
- **Ctrl+\_** — 撤销上一次输入编辑，连光标位置一起回
- **Ctrl+J · Shift+Enter · \\ + Enter** — 三种换行。`Ctrl+J` 任何终端都行；Windows Terminal 原生支持 Shift+Enter
- **Tab** — 接受补全；**在审批框上给「同意 / 拒绝」附一句注释**，把理由带进这一轮
- **? · :name: · 拼写检查** — 空输入按 `?` 弹快捷键面板；`:` 开头打 emoji 短码；输入框会标出拼错的词
- **vim 编辑模式** — `/config` → Editor mode。NORMAL / INSERT、文本对象、可视模式都在
- **按住空格** — 语音听写（要先开）。`/voice tap` 改成按一下切换

### 翻历史与找东西

- **{ · }** — 转录视图里跳到上 / 下一条你的提问，像 vim 的段落移动。要开 fullscreen 渲染
- **[** — *把整段对话写进终端原生 scrollback*，然后就能用 Cmd+F、tmux 复制模式这些原生工具搜它
- **v** — 把对话写成临时文件用 `$EDITOR` 打开
- **Esc Esc** — 输入框有字＝清空并存进历史（`Up` 能召回）；输入框空＝打开回溯菜单

## 上下文经济

这一节没有一个开关可拨，全是习惯。事实取自你自己那份 `docs/evidence/claude-code.md`（2026-08-21 核验），不是我现推的。核心只有一句：**缓存是前缀精确匹配，前缀里任何一处变了，它后面全部重算。**

- **改 agent-guide 中途不生效** — CLAUDE.md 与它内联的 agent-guide 在*会话开始时*加载。中途改完不 `/clear`，我读的还是旧版——而你改它的频率很高，这条最容易让你以为规则已经生效
- **回退比压缩便宜** — `/rewind` 是回到一个*已经在缓存里*的旧前缀；`/compact` 要造一个新前缀，后面全部重算
- **一个 issue 一个会话** — 靠自动压缩续命的会话会开始忘事、推翻自己刚做的决定。换任务就清空，成本是零
- **别中途换档** — 模型和 effort 档也进缓存键。中途换模型、换 effort、开 `/fast`、连断 MCP，都是整条历史重算
- **deny 裸工具名最贵** — 整条 deny 掉一个工具会把它从*系统提示词*里摘掉——那是最外层，一改全废。要收紧走 `ToolName(specifier)` 粒度
- **worktree 不共享缓存** — 缓存作用域里嵌了工作目录，同一仓库的两个 worktree 互不命中；同目录并行的会话反而彼此命中
- **压缩是两级** — 先清早期工具输出，再摘要对话——和本仓 §9.10「先裁剪后摘要」同构。CLAUDE.md 里可以写 Compact Instructions 指定保留什么
- **不失效的那几件** — 改仓库文件、换权限模式、调用命令与技能、派生子智能体、`/rewind`——这些随便用，不花钱

## 推理档与第二意见

「换个模型」不是唯一一个旋钮。下面四个都能单独调，而且**前三个都进缓存键**——中途改，整条历史重算，这一点上一节已经说过。

- ✓ **/effort** — 取值是 `low` → `xhigh`，再往上还有 `max` 和 `ultracode`，也可以交给 `auto`。*你现在钉在 xhigh，上面还有两档没试过*
- ◇ **extended thinking** — `Alt+T` 当场开关。Fable 5 无所谓，它永远在思考
- ◇ **fast mode** — `/fast` 或 `Alt+O`。是 Opus 输出更快，**不是换小模型**
- ◇ **advisor** — *在关键节点自动找第二个模型问一句*。`/advisor <model>` 指定谁来当这个顾问。**你的规矩是「评审要顶回去」，这条等于把顶回去的人内置了**

## 抽屉背面：三笔账

每一个「可用但没碰」的东西打开之后都有代价。这三笔现在就成立，其中第一笔正在生效。

#### 冲突 auto 模式把 `/rewind` 的「恢复代码」掏空了

你现在开着 `autoMode`，它让我优先用 bash（`sed` / heredoc）改文件。而检查点*只收文件编辑工具做的改动，bash 改的不追踪*——官方文档自己列在 Limitations 里。结果是：每条 prompt 仍然建检查点，但「恢复代码」那一档基本是空的，只剩「恢复对话」有用。

> 指望 /rewind 兜底的那种改动（多文件重构、大段重写）要明确说「用 Edit 改」；否则安全网只有 git

#### 税 worktree 的隐藏成本是一次冷启动

上面第 03 条建议 PR 挂评审时开 worktree。代价是缓存作用域里嵌了工作目录，新 worktree 一次都不命中，等于整条上下文重付一遍。

> 值不值取决于那条并行的活有多长——开个 worktree 去跑五分钟的活是亏的

#### 陷阱 配了 hooks 之后，`-p` 会在没信任过的目录里跑它们

不带 `--bare` 的 `claude -p` 会执行项目 `.claude/settings.json` 里的 hooks、连上 `.mcp.json` 里的 server，*即使这个目录从没被信任过，且不弹信任对话框*。第 01 条把检查挂上 hooks 之前先想清楚这条。

> 这是你那条红线「护栏不是沙箱」在工具自己身上的一次复现

## 交给新人时的顺序

上面全是「有什么」。这一节是「按什么顺序打开」——顺序错了，前两周基本在白付学费。对你自己也有用：这是一份可以核对的自检表。

#### 第一次 先别让它写代码

在**项目根目录**启动（会话与目录绑定，从子目录起它看不见上面的东西）。只问三个只读问题：这个仓库怎么组织、某个功能在哪实现、这段为什么这么写。

> 目的不是拿答案，是建立「它读得懂多少、读错时长什么样」的直觉。这一步零风险

#### 第一天 权限档停在手动，学会三个键

别一上来全放行。每个审批框都是一次免费的观察——你能看见它准备跑什么，配合 `Ctrl+E` 让它自己解释。同时把 `Esc`（打断）、`Shift+Tab`（切模式）、`/clear`（清空重开）变成肌肉记忆。

> 这三个键决定了「它跑偏时你损失几分钟还是几十分钟」

#### 第一周 五个习惯

一个任务一个会话；复杂任务先要方案（plan 模式）；给靶子不给方向；每个 diff 都看；它做错时停一下，问「这条该不该写进 CLAUDE.md」。

> 靶子的判据：你能不能描述「做完之后应该是什么样」。描述不出来，这一轮就该先调研或先做探针

#### 两周后 才轮到扩展，且有固定顺序

自定义命令 → 收权限表 → 子智能体 → hooks → 无头模式。重复输入第三次的那段话，就该变成一个命令。

> 反过来先配 hooks 的人，配的是自己还没验证过的规矩

### 五个最贵的坑

- **一个会话干到底** — 上下文塞满 → 压缩 → 开始忘事。「它越用越笨」几乎都是这个，不是模型的问题
- **「不行，再试一次」** — 同样的信息喂回去只会得到同样质量的答案。要么给*新信息*（完整报错、日志、你手验的结果），要么清空重开
- **一次改十个文件** — 改动越大你越审不动，审不动就只能盲信。拆成一眼看得完的份量
- **以为它读过整个文件** — 它常常是 grep 到几行就下判断。关键处直接问：*你是根据哪几行得出这个结论的*
- **把 CLAUDE.md 写成禁令清单** — 没有理由的规则，它遇到边界情况不知道该不该套用，于是要么盲从要么绕开。写理由，它才判断得了这条在眼前场景成不成立

怎么算用好了，有一个可观测的信号：**你的时间从「读它写的代码」转移到「定义靶子和验收**」。前期必须逐行审，因为你在校准它；校准完之后，代码质量该交给测试和评审去兜。
